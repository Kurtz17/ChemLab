## Overview

ChemLab is an immersive Virtual Reality chemistry laboratory simulation built with Unity. The project focuses on two main practicum activities, strong acid dilution and acid-base titration. Users can practice laboratory safety procedures, wear proper PPE, handle laboratory tools, pour and mix solutions, perform titration using PP indicator and NaOH, clean equipment, and receive evaluation feedback based on their experiment performance.

## Features

- VR laboratory simulation using Unity XR and OpenXR
- PPE system with lab coat, gloves, and safety goggles
- Interactive lab tools such as beaker, burette, pipette, erlenmeyer flask, stirrer, and sink
- Strong acid dilution simulation
- Acid-base titration simulation
- Spill, temperature, pouring speed, and volume evaluation
- Experiment result and performance feedback

## Simulation Flow

1. User starts from the main menu.
2. User enters the briefing room.
3. User reads the instructions and wears PPE.
4. User enters the laboratory.
5. User performs dilution or titration simulation.
6. The system evaluates the result and displays feedback.
